# camerawork

Turn a high-resolution screen recording into a guided video tour: camerawork finds where the screen changes,
plans a calm camera path that zooms and pans to each change (optionally steered by cues from a capture script),
and renders it with a presentation look (backdrop, rounded corners, shadow, tilt) into web-ready mp4 and webm.

**Status:** in design. See [the design spec](docs/superpowers/specs/2026-10-17-camerawork-design.md).

Requires ffmpeg and ffprobe 6 or later on `PATH`. MIT licensed.
